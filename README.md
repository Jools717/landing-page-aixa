# AIXA Landing Page

Landing Page corporativa desarrollada para AIXA.

El objetivo principal del proyecto es construir una experiencia premium orientada a la conversión de empresas interesadas en implementar soluciones de Inteligencia Artificial.

---

# Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript

---

# Filosofía del proyecto

El proyecto se desarrolla mediante un sistema de documentación.

Cada documento tiene una responsabilidad específica.

Antes de realizar cambios importantes, consultar la documentación correspondiente.
